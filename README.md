# Naevia

Naevia 是一款以 AI 角色陪伴为核心的私人像素生活游戏。玩家可以采集、布置小屋，与有独立记忆的女巫和铁匠交流。

## 开发入口

- [Demo 1 实现规范与验收清单](doc/SPEC.md)：开发者接手时的主要依据，包含技术选型、模块边界、交互流程、接口、本地记忆与存档、开发阶段和验收目标。
- [产品需求](doc/PRD.md)：产品方向和 Demo 1 范围。
- [项目状态](doc/README.md)：高层进度与文档索引。

## 当前交付状态

先发布产品和技术规范。视觉资源仍在制作，待项目所有者确认完成后另行提交；此时不能将仓库中的素材缺失视为 Demo 范围缩减。

收到视觉交付后，从 SPEC 第 3.3 节开始清点并接入最终素材，再按第 8 节依次完成可玩前端、本地后端、真实模型、独立记忆、群聊和 Windows 构建，最终执行第 10 节完整验收。当前尚无已实现的游戏程序或后端。

Demo 1 的客户端、后端和存档在本地 Windows 电脑运行；真实 AI 对话通过云端模型 API 完成，需要联网。不需要账号、云存档或线上后端部署。
