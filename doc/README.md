# Naevia 文档

`doc/` 保存项目级的产品方向、系统设计与高层进度。单次 agent 沟通及详细执行记录放在项目根目录下的独立文件中；游戏代码、后端代码和运行资源放在对应目录中。

- [PRD.md](PRD.md)：产品方向、玩家体验和 Demo 1 范围。
- [SPEC.md](SPEC.md)：实现基线、模块职责、开发阶段和验收标准。

## 已确认的运行范围

- Demo 1 在本地 Windows 电脑运行，游戏客户端与后端位于同一台电脑。
- 世界、家具、对话历史和角色记忆保存在本地。
- 暂不需要账号、跨设备同步或线上后端部署。
- 真实 AI 对话仍通过云端模型 API，需要联网；本地运行不等于本地模型推理。
- Mock 模式用于离线开发；本地模型部署不在 Demo 1 范围内。

## 当前进度

SPEC 已覆盖 Demo 1 的技术路径、模块职责、接口、独立记忆与本地存档、实施阶段和验收目标，可作为开发接手基线。视觉资源正在独立制作，待确认完成后再单独提交到 GitHub；本次文档发布不代表视觉已经交付。当前尚无游戏或后端实现。

视觉交付后，下一位开发者按 SPEC 接入最终素材，搭建 Godot 可玩场景，再依次完成本地后端、真实模型、独立记忆、群聊和 Windows 导出。Demo 1 功能范围与验收要求保持不变。详细启动和导出说明将在实现后写入项目根目录的 `DEVELOPMENT.md`，并从此处链接。
